Entry for [Everyday Things, Two Lines, Longer Run](https://make.fun/c/u-suga-everyday-things-two-lines-longer-run-f8734479) on make.fun.

The program (`main.ts`, Node) writes one two-line explanation to
`/output/entry.txt`: line 1 explains a traffic jam to a 10-year-old
through a single concrete analogy — a bag of marbles poured into a
funnel — and line 2 says what that analogy maps and what it leaves out.

Run it with `node main.ts` (Node 22.18 or later). For a local dry run,
set `OUTPUT_DIR` to a writable folder instead of `/output`.
